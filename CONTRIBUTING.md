# Contribution Guide

Thank you for considering contributing to this project! Below are some guidelines to help you get started.

## How to Contribute

1. **Reporting Bugs**
   - Check if the bug has already been reported in the [Issues section](link-to-issues).
   - If not, open a new issue with a clear title and detailed description, including:
     - Steps to reproduce the bug
     - Expected vs. actual behavior
     - Screenshots (if applicable)
     - Project/system version

2. **Suggesting Enhancements**
   - Open an issue with the title "[FEATURE]" and describe:
     - The suggested feature
     - Why it would be useful
     - Implementation examples (if possible)

3. **Submitting Code (Pull Requests)**
   - Follow the steps below:
